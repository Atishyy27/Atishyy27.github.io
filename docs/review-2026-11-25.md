## Top 3 changes

### 1. Contact that works without a mail client
- Change: show the address as text with a Copy button on the home closing banner and in /about/#contact;
  move the form logic to `src/lib/contact.ts` with a 10 s timeout and typed outcomes (sent, opened mail
  app, http error, timeout, network error); keep Web3Forms as the real integration and the mailto
  fallback as the default when no key is set.
- Expected effect: address visible on 2 pages instead of 0 of 167; a stalled or failing relay ends in an
  error message with the address instead of a stuck button.
- Check: unit tests against a mocked Web3Forms (200, 500, timeout, network error, no key) and a mocked
  clipboard; built-page check that `/about/` and `/` contain the address as text.
- What the visitor notices: the email address is on the page, one tap copies it, and a form that fails says so.
- Risk: the address becomes scrapable plain text on two pages (it is already in the JSON-LD on every page,
  `layout.tsx:55`, so nothing new leaks). Low otherwise: the real Web3Forms path is unchanged.

### 2. Navigation and document basics
- Change: skip link as the first focusable element on every page; nav marks the current route with
  `aria-current="page"` and the accent colour; `Head` can render `h1`, used by /stats/ and /writing/, and
  /about/ gets a visually hidden h1.
- Expected effect: skip link on 167 of 167 pages (0 now), h1 on 167 of 167 (164 now), current page marked
  on the 5 nav routes (0 now).
- Check: unit tests for the active-route function; built-output check over every `index.html` in `out/`
  asserting one skip link and exactly one h1 (redirect stubs excluded).
- What the visitor notices: the current page is lit in the nav; a keyboard or screen-reader user gets a
  "Skip to content" link on first Tab; nothing changes for a mouse user except the lit nav item.
- Risk: `usePathname` in the shared nav on a static export (prerender gives the route, so expected fine,
  proven only by the CI build); the invisible h1 on /about/ is new text for crawlers.

### 3. Make the existing checks a gate
- Change: fix `check-orphans.mjs` so route-handler exports in `src/app` are entry points; add `npm test`
  (node:test) and `npm run check:fast` (the verify steps that need no build, minus `check:resume` which is
  red on content he owns); run `tsc --noEmit` and `check:fast` in `ci.yml` before the build, and the new
  built-output check after it.
- Expected effect: CI gates 8 more checks than the 2 it runs today (build, oss-numbers); the orphans
  false positive is gone.
- Check: the local `check:fast` run is green; the CI run on the pushed branch is green.
- What the visitor notices: nothing directly. It stops the first two changes, and the data checks, from
  breaking unnoticed.
- Risk: CI needs Node 22 for the TypeScript-reading checks (the build job stays on 20), and a workflow
  file edit needs a token with workflow scope to push. A flaky new CI step would block his merges.

## Try it yourself (D6), about five minutes

Setup once: in the worktree on branch `review/2026-11-25`, run `npm ci` (already done there), then
`npm run dev`, and open http://localhost:3000. Stop the server with Ctrl+C afterwards.

1. Contact address: open `/about/#contact`. The address sits above the form with a Copy button. Click
   Copy, paste into Notepad: it is the same address. The home page bottom banner has the same.
2. Failure states: stop the server, run `NEXT_PUBLIC_WEB3FORMS_KEY=test NEXT_PUBLIC_MOCK_API=1 NEXT_PUBLIC_MOCK_MODE=500 npm run dev`
   (on Windows set the three variables first), fill the form and send. It says "Something broke" and
   shows the address. Change MOCK_MODE to `timeout`: after 10 seconds it says "That took too long" and
   the button comes back. With MOCK_MODE unset it says "Sent". No real request leaves the machine.
3. Keyboard: on the home page press Tab once. A "Skip to content" button appears top left. Press Enter:
   focus moves into the page. Press Tab again and it is on the first control of the page, not the nav.
4. Current page: click Stats in the nav. It turns the accent colour and stays that way on /stats/.
   Open any project page: Projects stays lit. The home page lights nothing.
5. The gate: `npm run check:fast` prints PASS lines and "ALL PASS" in about six seconds. To see what
   it fixed: `git checkout origin/main -- scripts/check-orphans.mjs`, run `npm run check:orphans`
   (FAIL on the llms.txt route), then `git checkout HEAD -- scripts/check-orphans.mjs`.
